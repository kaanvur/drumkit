🥁 3D Printed Bluetooth MIDI Drum Kit!

Built a compact electronic drum kit using ESP32-C3 Super Mini + piezo sensors. All parts are 3D printed!

Features:
• 5 velocity-sensitive pads (kick, snare, hi-hat, tom, cymbal)
• Wireless BLE MIDI - works with GarageBand, BandLab, n-track
• Total cost under $15

The .3mf file has 6 color-coded build plates ready to print.

Full docs + Arduino code: https://github.com/kaanvur/drumkit

Happy to answer questions! 🎵
